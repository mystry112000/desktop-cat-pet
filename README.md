# 🐱 Desktop Cat Pet

A cute desktop cat with tamagotchi mechanics. Sits on your screen — feed it, play with it, watch it sleep.

**Repo:** https://github.com/mystry112000/desktop-cat-pet

## How to Run

### 1. Download
```bash
git clone https://github.com/mystry112000/desktop-cat-pet.git
cd desktop-cat-pet
```

### 2. Install (one time only)
```bash
npm install
```
This downloads Electron (the app engine).

### 3. Launch
```bash
npm start
```
Run this whenever you want your cat to appear.

## Features
- 🍽️ **Feed** — keeps your cat full
- 🎮 **Play** — makes your cat happy
- 😴 **Sleep** — recovers energy
- 🧘 **Stretch / 🥱 Yawn / 🫳 Scratch** — fun animations
- 🖱️ **Drag** — click anywhere and drag to move the cat around
- 🔔 **Notifications** — alerts you when your cat needs care
- 🎨 **5 color skins** — peach, gray, black, cream, brown
- ✏️ **Custom name** — click the name to rename your cat
- 💬 **Speech bubbles** — your cat talks to you
- 📉 **Passive decay** — hunger, happiness, energy drop over time
