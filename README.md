# 🐱 Desktop Cat Pet

A cute desktop cat with tamagotchi mechanics. Feed it, play with it, watch it sleep. Sits on your screen as a frameless always-on-top window.

## Features
- 🍽️ Feed / 🎮 Play / 😴 Sleep
- 🎨 5 color skins (peach, gray, black, cream, brown)
- ✏️ Custom name
- 💬 Speech bubbles
- Passive decay — needs care

## Run
```bash
npm install
npm start
```
