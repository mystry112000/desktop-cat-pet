📦 How to Install

Just 3 simple steps

1

Download

Click the download button above to get the ZIP file, then extract it anywhere.

desktop-cat-pet-main.zip
2

Install (one time only)

Open a terminal in the extracted folder and run:

npm install

This downloads the engine that runs the app.

3

Launch

Run this whenever you want your cat to appear:

npm start

Your cat window pops up — frameless, always-on-top, and ready to play!
